# 괄호 짝 맞추기

`solution.py`의 `is_balanced(s)`를 구현하라.

문자열 `s`는 `()`, `{}`, `[]` 세 종류의 괄호 문자로만 이루어진다.
모든 여는 괄호가 같은 종류의 닫는 괄호와 **올바른 순서로** 짝지어지면 `True`,
아니면 `False`를 반환하라.

올바른 괄호 문자열의 조건:

1. 여는 괄호는 같은 종류의 닫는 괄호로 닫혀야 한다.
2. 닫히는 순서가 여는 순서와 맞아야 한다(가장 최근에 열린 괄호가 먼저 닫힌다).

## 예시

```
is_balanced("()[]{}")  -> True
is_balanced("(]")      -> False
is_balanced("{[()]}")  -> True
```

## 제약

- 빈 문자열은 `True`로 간주한다.
