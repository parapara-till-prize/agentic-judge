# 로그 파서 확장

서버 로그 포맷이 업데이트됐다. 기존에는 타임스탬프가 없었지만 장애 대응을 위해 추가됐다.

| 구분 | 포맷                                  |
| ---- | ------------------------------------- |
| 기존 | `[INFO] 메시지`                       |
| 신규 | `[2024-01-15 09:30:00] [INFO] 메시지` |

`log_entry.py`의 `parse()` 함수가 새 포맷을 처리하도록 수정하라.

- 반환: `(timestamp, level, message)` 튜플
- 파싱 실패 시 `ValueError`

```python
ts, lv, msg = parse("[2024-01-15 09:30:00] [INFO] 서버가 시작됐습니다")
# ts  == "2024-01-15 09:30:00"
# lv  == "INFO"
# msg == "서버가 시작됐습니다"
```
