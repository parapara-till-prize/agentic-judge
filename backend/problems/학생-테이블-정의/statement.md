## 문제: 학생 정보 조회하기

### 테이블 구조

다음 두 테이블을 정의합니다:

**`학생` 테이블**
| 컬럼명 | 타입 | 설명 |
|---|---|---|
| 이름 | TEXT | 학생의 이름 |
| 학번 | TEXT | 학생의 고유 학번 (기본 키) |
| 학과 | TEXT | 학생이 소속된 학과 |

**`강의` 테이블**
| 컬럼명 | 타입 | 설명 |
|---|---|---|
| 강의명 | TEXT | 강의의 이름 |
| 학과 | TEXT | 강의가 개설된 학과 |
| 학수번호 | TEXT | 강의의 고유 학수번호 (기본 키) |

### 문제 설명

`학생` 테이블에 있는 모든 학생의 **이름, 학번, 학과** 정보를 조회하는 SQL 쿼리를 작성하세요.

### 예시 데이터 (학생 테이블)

| 이름 | 학번 | 학과 |
|---|---|---|
| 김철수 | 20230001 | 컴퓨터공학과 |
| 이영희 | 20230002 | 전자공학과 |
| 박지민 | 20230003 | 컴퓨터공학과 |

### 예상 결과

| 이름 | 학번 | 학과 |
|---|---|---|
| 김철수 | 20230001 | 컴퓨터공학과 |
| 이영희 | 20230002 | 전자공학과 |
| 박지민 | 20230003 | 컴퓨터공학과 |

### 제약 조건
- `학생` 테이블의 모든 컬럼을 명시적으로 선택해야 합니다. (`SELECT *`는 사용하지 마세요.)
