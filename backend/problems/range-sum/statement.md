# 구간 합 구하기

`solution.py`의 `range_sum(arr, queries)`를 구현하라.

정수 배열 `arr`와 질의 목록 `queries`가 주어진다. 각 질의는 `(i, j)` 튜플이며,
**1-indexed**로 `i`번째부터 `j`번째 원소까지(양끝 포함)의 합을 의미한다.

각 질의에 대한 구간 합을 **질의 순서대로** 리스트로 반환하라.

> 주의: `i`가 `j`보다 클 수도 있다. 이 경우 `(j, i)`와 동일한 구간으로 취급한다.

## 예시

```
arr = [5, 4, 3, 2, 1]
queries = [(1, 3), (2, 4), (1, 5)]
반환: [12, 9, 15]
```

## 제약

- `1 ≤ i, j ≤ len(arr)`
- 원소는 음수일 수 있다.
