# 반응형 스티키 네비게이션

`index.html`, `styles.css`, `app.js`를 수정하여 **반응형 스티키 네비게이션 바**를 구현하라.

## DOM 계약 (채점 셀렉터)

- 네비게이션 바의 컨테이너는 `<nav>` 태그를 사용한다.
- 로고 역할을 하는 요소 하나와 링크 요소(`<a href="#">`)가 **3개 이상** 포함되어야 한다.
- 모바일에서 메뉴를 토글하는 햄버거 버튼( `<button data-testid="hamburger">` )이 존재해야 한다.
- 햄버거 버튼이 클릭되었을 때 메뉴가 열렸는지 닫혔는지 상태를 나타내는 `aria-expanded` 속성을 햄버거 버튼에 사용해야 한다.

## 요구사항

1. **데스크톱(폭 ≥ 768px)** — 로고와 링크들이 가로로 나란히 배치된다. 햄버거 버튼은 화면에 보이지 않는다.
2. **모바일(폭 < 768px)** — 링크들이 화면에 보이지 않고 햄버거 버튼이 나타난다. 햄버거 버튼을 클릭하면 링크들이 세로로 나열된 메뉴가 토글(표시/숨김)된다.
3. **스티키 헤더** — 페이지를 아래로 스크롤할 때 네비게이션 바가 화면 최상단에 고정(`position: sticky` 또는 `fixed`)되어야 한다. 배경색을 지정하여 내용과 겹쳤을 때 구분이 가능해야 한다.
4. **접근성** — `<nav>` 랜드마크 사용, 햄버거 버튼에 `aria-expanded` 속성을 상태에 맞게 토글, 버튼에 텍스트나 `aria-label` 부여 등 접근성 위반이 없어야 한다.

## 예제 테스트

`node tests/run_visible.js` 가 헤드리스 브라우저로 페이지를 띄워 기본 구조(`<nav>`, 링크 개수, 햄버거 버튼 존재)를 확인한다.

> 예제 테스트는 구조만 본다. 제출 채점은 데스크톱/모바일 레이아웃, 스크롤 고정 여부, JS 토글 동작, 접근성까지 **렌더된 결과**로 검증한다.
