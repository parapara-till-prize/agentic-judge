# 로그 재정렬 API

`solution.py`의 `reorder_logs(logs)`를 구현하라.

각 로그는 공백으로 구분된 문자열이며, **첫 토큰은 식별자(identifier)**, 나머지는 **내용(content)**이다.

- **문자 로그(letter-log):** 내용이 영문자로만 이루어진 로그.
- **숫자 로그(digit-log):** 내용이 숫자로만 이루어진 로그.

재정렬 규칙:

1. 모든 문자 로그가 모든 숫자 로그보다 **앞**에 온다.
2. 문자 로그끼리는 **내용 기준 사전순**으로 정렬한다. 내용이 같으면 **식별자 기준 사전순**으로 정렬한다.
3. 숫자 로그끼리는 **입력에 들어온 원래 순서를 그대로 유지**한다.

## 예시

```
입력:  ["let1 art can", "dig1 8 1 5 1", "let2 own kit dig", "let3 art zero", "dig2 3 6"]
출력:  ["let1 art can", "let3 art zero", "let2 own kit dig", "dig1 8 1 5 1", "dig2 3 6"]
```

## 제약

- 식별자와 내용 토큰은 비어 있지 않다.
- 로그 개수 0개 이상.
